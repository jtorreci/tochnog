# Divergences with Tochnog Professional

Single index of every known difference between the GNU version and Tochnog Professional (binary 02-08-2026 and its manual): deliberate, known, pending, dialect and Professional-suspect. Detailed evidence lives in the documents linked from each row.

## Principle

- The Professional manual, or the analytic answer, decides.
- When the manual is silent, the Professional binary is the oracle.
- Not following the Professional needs a project-owner decision. The decision is recorded in the "Descarte de features" table of [SEGUIMIENTO-CONVERGENCIA.md](SEGUIMIENTO-CONVERGENCIA.md) and in the "Differences with the Professional version" section of the user and developer manual pages of the feature.
- Every divergence (deliberate, known or pending) is listed here (AGENTS.md, "Convergence tracking").

## Classes

| class | meaning | items |
|---|---|---|
| A | deliberate divergence decided by the project owner | 10 |
| B | known difference, not decided yet or scheduled (F3/F4) | 38 |
| C | GNU extension or input-dialect difference | 16 |
| D | Professional-suspect: the Professional contradicts its own manual or the analytic answer | 4 |
| | **total** | **68** |

Ids: `C*`/`B*` are [BACKLOG-OPEN-ISSUES.md](BACKLOG-OPEN-ISSUES.md) items, `K*` are clusters of [AUDIT-ALL-VARIABLES-2026.md](AUDIT-ALL-VARIABLES-2026.md); other ids are local to this index. Several class A items are also Professional-suspect (noted in their status). Professional values are from the binary 02-08-2026 unless stated.

Not listed: differences that were closed by following the Professional (for example the `convection_apply` and default memory alignments, R1-R10, C5, C28) and stale sfnet targets (B1-B12), which are not divergences.

## Maintenance

- Add a row when a difference is found, in the same work unit, with its class. Move it between classes when the owner decides.
- Class A and D rows need a SEGUIMIENTO "Descarte de features" row.
- Every row with a feature page needs a bullet in the "Differences with the Professional version" section of the user and developer pages. Rows without a page say so in "documented in".
- When a difference is closed by following the Professional, remove the row and record the fix in SEGUIMIENTO.
