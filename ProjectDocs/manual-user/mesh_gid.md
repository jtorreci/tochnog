# mesh_gid family (GiD geometry)

Geometry records for meshing with GiD as a batch preprocessor (manual Professional
6.818-6.853). They are only used by [control_mesh_gid_batch](control_mesh_gid_batch.md):
without it they are accepted and ignored.

## Records

| Record | Syntax | Meaning |
|---|---|---|
| `mesh_gid_point_coord` | `index x y` (2D) / `index x y z` (3D) | point |
| `mesh_gid_line_point` | `index point_0 point_1` | straight line between two GiD points |
| `mesh_gid_line_element_group` | `index group` | group of the line elements |
| `mesh_gid_line_size` | `index size` | element size on the line |
| `mesh_gid_line_structured_nel` | `index nel` | number of elements on a structured line |
| `mesh_gid_line_structured_size` | `index size` | element size on a structured line |
| `mesh_gid_line_structured_concentrate` | `index weight_start weight_end` | concentration at the line start and end, each between -1 and +1 (default 0) |
| `mesh_gid_arc_coord` | `index x_0 y_0 x_1 y_1 x_2 y_2` | arc through three points (2D) |
| `mesh_gid_circle_coord` | `index x y` | circle centre (2D) |
| `mesh_gid_circle_radius` | `index radius` | circle radius (required with the centre) |
| `mesh_gid_circle_hollow` | `index switch` | `-yes`: only the circle edge (two arcs), no surface |
| `mesh_gid_circle_element_group` | `index group` | group of the circle surface |
| `mesh_gid_rectangle_coord` | `index x_0 x_1 y_0 y_1` | rectangle between (x_0,y_0) and (x_1,y_1) |
| `mesh_gid_rectangle_hollow` | `index switch` | `-yes`: the rectangle surface is deleted, only its edges remain |
| `mesh_gid_rectangle_element_group` | `index group` | group of the rectangle surface |
| `mesh_gid_cylinder_coord` | `index x y z` | centre of the base (3D) |
| `mesh_gid_cylinder_normal` | `index normal_x normal_y normal_z` | axis direction (required) |
| `mesh_gid_cylinder_radius` | `index radius` | radius (required) |
| `mesh_gid_cylinder_height` | `index height` | height (required) |
| `mesh_gid_cylinder_hollow` | `index switch` | `-yes`: the cylinder volume is deleted (for example an excavation) |
| `mesh_gid_cylinder_element_group` | `index group` | group of the cylinder volume |
| `mesh_gid_sphere_coord` | `index x y z` | centre (3D) |
| `mesh_gid_sphere_radius` | `index radius` | radius (required) |
| `mesh_gid_sphere_hollow` | `index switch` | `-yes`: the sphere volume is deleted |
| `mesh_gid_sphere_element_group` | `index group` | group of the sphere volume |
| `mesh_gid_surface_line` | `index line_0 line_1 ...` | one new surface bounded by these GiD lines |
| `mesh_gid_surface_element` | `index element_type` | `-tria3`, `-tria6`, `-quad4`, `-quad8`, `-quad9`, `-tet4`, `-tet10`, `-hex8`, `-hex20`, `-hex27`; default linear (triangles in 2D, tets in 3D) |
| `mesh_gid_surface_element_group` | `index group` | group of the surface elements |
| `mesh_gid_surface_structured_nel` | `index nel_0 nel_1 ...` | one number per surface line; a positive number sets the elements of that line, 0 for the opposite lines |
| `mesh_gid_surface_structured_size` | `index size` | element size on a structured surface |
| `mesh_gid_volume_surface` | `index surface_0 surface_1 ...` | one new volume bounded by these GiD surfaces (3D) |
| `mesh_gid_volume_element_group` | `index group` | group of the volume elements |
| `mesh_gid_assign_conditions_point` | `index point_0 point_1 ...` | nodes on these GiD points go to `geometry_list index`, index 1 ... 10 |
| `mesh_gid_assign_conditions_line` | `index line_0 line_1 ...` | nodes on these GiD lines go to `geometry_list index`, index 11 ... 20 |
| `mesh_gid_assign_conditions_surface` | `index surface_0 surface_1 ...` | nodes on these GiD surfaces go to `geometry_list index`, index 21 ... 30 |
| `mesh_gid_size` | `element_size` (no index) | element size of the mesh (required) |

Use the group numbers 1, 2, 3, ... without gaps.

## GiD numbers

Point numbers in `mesh_gid_line_point`, line numbers in `mesh_gid_surface_line` and
`mesh_gid_assign_conditions_line`, and surface numbers in `mesh_gid_volume_surface` and
`mesh_gid_assign_conditions_surface` are GiD numbers, not record indices. GiD numbers the
entities in the order Tochnog creates them:

1. points, lines (in index order);
2. circles, arcs, rectangles, cylinders, spheres (each type in index order);
3. surfaces (`mesh_gid_surface_line`), then volumes (`mesh_gid_volume_surface`).

Each object adds:

| Object | Points | Lines | Surfaces | Volumes |
|---|---|---|---|---|
| point | 1 | | | |
| line | | 1 | | |
| circle | 1 | 1 | 1 | |
| hollow circle | 2 | 2 | | |
| arc | 3 | 1 | | |
| rectangle | 4 | 4 | 1 (none when hollow) | |
| cylinder | 4 | 6 | 4 | 1 (none when hollow) |
| sphere | 2 | 4 | 4 | 1 (none when hollow) |

With `echo -yes` the run prints the numbers each record generates, for example:

```
generated by MESH_GID_RECTANGLE index: 1
   point numbers: 10 11 12 13
   line numbers: 8 9 10 11
   surface numbers: 1
```

## Input errors

- `mesh_gid_size` is missing.
- A circle without radius, a cylinder without normal, radius or height, a sphere without
  radius.
- `mesh_gid_line_structured_concentrate` weights outside [-1, +1].
- `mesh_gid_surface_structured_nel` without one number per surface line.
- `mesh_gid_assign_conditions_*` indices that do not start at the first index of the range
  (1, 11, 21), have gaps, or leave the range.
- Cylinders, spheres or volumes in 2D; arcs in 3D.

## Differences with the Professional 02-08-2026

- A `mesh_gid_assign_conditions_*` index below its range is ignored by the Professional;
  GNU stops with an input error.
- The Professional finds the input errors while it writes the batch file (it keeps a partial
  file); GNU checks before writing.
- Circles in 3D: the Professional writes a broken command line and no circle; GNU writes
  nothing for them.
- `mesh_gid_volume_element_group` writes `Mescape Data Mat Assign <group> Volume`, not the
  `GROUP_<group> Volumes` of cylinders and spheres (Professional-suspect, reproduced byte by
  byte).

See also [control_mesh_gid_batch](control_mesh_gid_batch.md).
