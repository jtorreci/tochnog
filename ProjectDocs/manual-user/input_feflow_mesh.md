# input_feflow_mesh

## Descripción

`input_feflow_mesh -yes` imports a finite element mesh generated by FEFLOW
from the file `feflow.fem` (ASCII, with `coordinates` and `elements`
sections). It fills the Tochnog node and element database directly.

Supported elements:

| Element nodes | Tochnog element |
|---------------|-----------------|
| 2             | bar2            |
| 3             | tria3           |
| 4             | quad4           |
| 6             | tria6           |
| 9             | quad9           |

Elements with any other node count are skipped.

## Uso

Place it in the data part, as a keyword line:

```
input_feflow_mesh -yes
```

The file `feflow.fem` must exist in the working directory.

## Parámetros

| Parameter | Meaning                                                    |
|-----------|------------------------------------------------------------|
| `input_feflow_mesh -yes/-no` | `-yes` imports the FEFLOW mesh (default `-no`). |
| `input_feflow_fem -yes/-no`  | `-yes` reads the mesh from `feflow.fem`; `-no` reads it from `feflow.dac`. Default `-yes`. |
| `input_feflow_mesh_hydraulic_head` | Pending (not implemented). |

## Ejemplo

Minimal input that imports a FEFLOW mesh and runs a static calculation:

```
input_feflow_mesh -yes

control_geometry
   cartesian
control_time
   end 1.0
   dt 0.1
control_print
   history 0
   step 10
materi_elasti_young
   0 2.e7
materi_elasti_poisson
   0 0.3
materi_density
   0 2500.
bounda_force
   1 2 0 -1000.
end_data
```

The nodes and elements come from `feflow.fem`; the rest of the input applies
materials and boundary conditions to the imported mesh.
