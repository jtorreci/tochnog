# control_print_gid_contact_spring2

GiD rendering switch of the contact_spring2 elements (manual Professional
6.297): 2 = draw with two nodes, 1 = draw with one node; default 1. The short
Professional spelling `print_gid_contact_spring2 <value>` (tutorial_3 of the
corpus) is accepted as an alias. Registered parse-only: the GNU GiD printer
draws the contact springs with the element nodes of the model.
