# to_pres

## Description

`-to_pres` is the item name (value name of `target_item` /
`post_point_dof_calcul`) generated by

```
post_calcul -groundflow_pressure -total_pressure
```

It holds the TOTAL groundwater pressure (pore pressure + static
pressure from the phreatic level) at the post location. The sibling
items of the groundflow pressure split are `-st_pres`
(`-static_pressure`) and `-dy_pres` (`-dynamic_pressure`).

Target example:

```
post_calcul -groundflow_pressure -total_pressure
post_point 10  0.5 -0.5
...
target_item  1   -post_point_dof_calcul 10 -to_pres
target_value 1   -5 1.
```

## Uso

Use the item name in `target_item`/`control_print` records exactly as
shown above (Professional `post_calcul_label` naming).

## Parámetros

| Item | post_calcul pair | Meaning |
|------|------------------|---------|
| `-to_pres` | `-groundflow_pressure -total_pressure` | pres + static pressure. |
| `-st_pres` | `-groundflow_pressure -static_pressure` | static (phreatic) pressure only. |
| `-dy_pres` | `-groundflow_pressure -dynamic_pressure` | dynamic (excess) pressure only. |

## Verification / status

The target name resolution works (ground8 fails only on the physical
value: GNU total pressure −76.9 vs Professional −10 at the same point
— the multiple-phreatic-level static convention of the Professional is
not reproduced yet).
