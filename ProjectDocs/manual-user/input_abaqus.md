# input_abaqus

## Descripción

`input_abaqus` imports a finite element mesh generated by Abaqus from the
file `abaqus.inp`. It converts the nodes and elements into Tochnog records,
writes them to `tochnog_abaqus.dat`, and optionally writes group records
for the elastic material. The generated file is then included into the
input with `include tochnog_abaqus.dat`.

Typical flow:

```
input_abaqus -yes
input_abaqus_continue -yes
include tochnog_abaqus.dat
```

## Uso

The conversion runs in two steps:

1. `input_abaqus -yes` stores the switch; it must be followed by the
   `input_abaqus_*` sub-options.
2. `input_abaqus_continue -yes` triggers the actual read of `abaqus.inp` and
   the generation of `tochnog_abaqus.dat`. It must be the last sub-option.

Supported element conversions:

| Abaqus element types                       | Tochnog element |
|--------------------------------------------|-----------------|
| T2D2, T3D2                                 | bar2            |
| T2D3, T3D3                                 | bar3            |
| CPS3, CPE3, CAX3, S3                       | tria3           |
| CPS6, CPE6                                 | tria6           |
| CPS4, CPE4, CAX4, M3D4                     | quad4           |
| CPS8, CPE8, CAX8, M3D8                     | quad9           |

Element types outside this list are skipped with a warning.

## Parámetros

| Parameter | Meaning                                                    |
|-----------|------------------------------------------------------------|
| `input_abaqus -yes/-no`        | Enable/disable the Abaqus import (default `-no`). |
| `input_abaqus_continue -yes/-no` | `-yes` reads `abaqus.inp` and generates `tochnog_abaqus.dat`. Must be the last sub-option. |
| `input_abaqus_group -yes/-no`  | `-yes` converts the `*Elastic` material into `group_materi_elasti_young` / `group_materi_elasti_poisson` + `group_materi_memory` records. Default `-yes`. |
| `input_abaqus_name 0 -bar2 -tria3 ...` | Filters which element types are converted. Given a list of negated Tochnog element names; empty means all. |
| `input_abaqus_set 2 5`         | Filters which elements are written by element number. Empty means all. |
| `input_abaqus_mesh -yes/-no`   | Pending (not implemented). |

## Ejemplo

Minimal input that imports an Abaqus mesh with the default elastic group:

```
input_abaqus -yes
input_abaqus_continue -yes
include tochnog_abaqus.dat

control_geometry
   cartesian
control_time
   end 1.0
   dt 0.1
control_print
   history 0
   step 10
end_data
```

`abaqus.inp` must exist in the working directory. The generated
`tochnog_abaqus.dat` contains the `node`, `element` and `group_materi_*`
records and is processed by the `include`.
