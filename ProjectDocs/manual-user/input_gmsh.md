# input_gmsh

## Descripción

`input_gmsh -yes` imports a finite element mesh generated by Gmsh from the
file `tochnog_in.msh` (Gmsh 2.2 ASCII format). It reads the nodes and the
elements of the mesh into the Tochnog database. The mesh is read from the
working directory.

Only the element types that Tochnog supports are imported:

| Gmsh element type | Tochnog element |
|-------------------|-----------------|
| 1                 | bar2            |
| 8                 | bar3            |
| 2                 | tria3           |
| 9                 | tria6           |
| 3                 | quad4           |
| 10                | quad9           |

Three-dimensional elements (tetrahedra, hexahedra, wedges) are NOT
supported: Tochnog has no equivalent element types, so the import aborts.

## Uso

Place it in the data part, as a keyword line:

```
input_gmsh -yes
```

The file `tochnog_in.msh` must exist in the working directory.

## Parámetros

| Parameter | Meaning                                                    |
|-----------|------------------------------------------------------------|
| `-yes`    | Import the mesh from `tochnog_in.msh`.                     |
| `-no`     | Do not import (default).                                   |

## Ejemplo

Minimal input that imports a Gmsh mesh and runs a static calculation:

```
input_gmsh -yes

control_geometry
   cartesian
control_time
   end 1.0
   dt 0.1
control_print
   history 0
   step 10
materi_elasti_young
   0 2.e7
materi_elasti_poisson
   0 0.3
materi_density
   0 2500.
bounda_force
   1 2 0 -1000.
end_data
```

The nodes and elements come from `tochnog_in.msh`; the rest of the input
applies materials and boundary conditions to the imported mesh.
