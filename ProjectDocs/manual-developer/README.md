# Tochnog — Developer Manual (GNU version)

Technical documentation of the features implemented in the GNU version of Tochnog.
For each feature: where it was implemented, implementation details, external
features/libraries used, hardcoded parameters, and refactorings.

Each file corresponds to the same feature in the [User Manual](../manual-user/).
