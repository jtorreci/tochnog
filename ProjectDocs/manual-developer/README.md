# Tochnog — Developer Manual (GNU version)

Technical documentation of the features implemented in the GNU version of Tochnog.
For each feature: where it was implemented, implementation details, external
features/libraries used, hardcoded parameters, and refactorings.

Each file corresponds to the same feature in the [User Manual](../manual-user/).

## Input of meshes and files (P0)

- [include](include.md) — include external data files into the data part.
- [input_gmsh](input_gmsh.md) — import a mesh generated by Gmsh.
- [input_abaqus](input_abaqus.md) — import a mesh generated by Abaqus.
- [input_feflow_mesh](input_feflow_mesh.md) — import a mesh generated by FEFLOW.

## Phase 4 features

- [groundflow_pressure_factor](groundflow_pressure_factor.md) — scale the pore-pressure contribution to the total stress.
- [group_groundflow_permeability_vertical_stress](group_groundflow_permeability_vertical_stress.md) — stress-dependent groundflow permeability (groundda.cc groundflow_data, extended signature).

- [group_materi_viscosity](group_materi_viscosity.md) — viscosity (viscosit.cc viscous_stress; user.cc stub).
- [group_materi_damage_mazars](group_materi_damage_mazars.md) — Mazars damage (damage.cc; epseq accumulation bug fixed 2026-08-10).

- [group_materi_plasti_visco_exponential](group_materi_plasti_visco_exponential.md) — viscoplasticity (stress.cc:100-115, 737-755; EPS_VISCO hardcoded).
- [group_materi_plasti_mohr_coul_direct](group_materi_plasti_mohr_coul_direct.md) — direct stress cut-off (materi_direct_cutoff in stress.cc).
- [group_materi_plasti_hypo_masin](group_materi_plasti_hypo_masin.md) — Masin clay hypoplasticity (masin.c pure-C port of umat_hcea.for, validated to 5e-7; hypoplas.cc dispatch).
- [group_materi_plasti_sanisand](group_materi_plasti_sanisand.md) — SANISAND (sanisand.c port of the Dafalias-Manzari UMAT; functional ~8% vs Fortran, integrator tightening pending in P4-E1b).
- [group_materi_plasti_hypo_wolfersdorff](group_materi_plasti_hypo_wolfersdorff.md) — hypoplasticity kernel (hypo.c pure-C, all 5 variants verified).

## Cross-cutting notes

- Enum consistency: `tochnog.h` and `tochnog-mod.h` must stay in sync.
- Build: only clean builds are reliable on the current filesystem; linking to
  `/tmp` and copying the binary avoids I/O failures.
